Usage

Local request statistics for NekoSearch MCP tools.

Collection settings

Statistics stay in the local NekoSearch data directory. They are not sent to NekoSearch or any third party. Collection starts only after you enable it here.

Fingerprints group repeat queries without saving their exact text. Raw mode stores exact queries. The local SQLite database is not encrypted.

Request report

Response size is the UTF-8 size of the serialized MCP tool result. Documentation text is never saved in the usage database.
